📝 Notiz-App

Eine einfache und sichere Anwendung zur Verwaltung von Notizen, entwickelt mit Next.js, TypeScript und optional NextAuth zur Authentifizierung.

Die App ermöglicht es Benutzern, Notizen zu erstellen, zu bearbeiten, zu löschen und zu verwalten. Sie bietet eine übersichtliche Benutzeroberfläche und eine flüssige Benutzererfahrung.

🚀 Funktionen
🔐 Benutzerauthentifizierung mit NextAuth
📝 Notizen erstellen, bearbeiten und löschen
📄 Rich-Text- oder einfache Textnotizen
🌙 Dunkel- und Hellmodus
⚡ Schnelle Darstellung mit dem Next.js App Router
🎨 Responsives Design mit Tailwind CSS
🗄️ Datenbankunterstützung mit Prisma und SQLite/PostgreSQL
🛠️ Verwendete Technologien
Next.js 14+
React
TypeScript
Tailwind CSS
NextAuth.js
Prisma ORM
SQLite / PostgreSQL
